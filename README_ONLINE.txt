PALABRA RÁPIDA — ONLINE

ETAPA 4: CARTAS ESPECIALES SINCRONIZADAS

Esta versión conserva el modo local y agrega interacción online para las cartas especiales.

Incluye:
- Sala online de hasta 8 jugadores.
- Turnos y respuestas normales desde el dispositivo de cada jugador.
- CAMBIO: el jugador elige 3–10 letras.
- COMODÍN: el jugador elige la categoría.
- LETRA: el jugador de la izquierda elige la vocal.
- DUELO: se elige rival, se confirma con CONTINUAR y se sincroniza el duelo.
- DESEMPATE: los jugadores empatados pueden elegir al ganador desde sus dispositivos.
- Estado de partida y puntuaciones sincronizados por el servidor.

REQUISITOS
- Node.js 18+ recomendado.
- Ejecutar: npm install
- Luego: npm start
- Abrir en el navegador la dirección indicada por el servidor.

NOTA
Para jugar desde otros dispositivos de la misma red, el servidor debe ser accesible desde esos dispositivos. Para jugar por Internet, hay que publicar el servidor en un servicio de hosting compatible con Node.js/WebSocket.
